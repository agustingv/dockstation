DockStation v@VERSION@

Tus proyectos de Docker Compose, en un solo sitio.

DockStation es una aplicación de GNOME para arrancar, parar y editar tus proyectos, seguir sus registros y crear otros nuevos a partir de plantillas, sin escribir un comando.

Debian y Ubuntu

.deb

Debian 13 y Ubuntu 25.10 o posterior. Ubuntu 24.04 no sirve: su libadwaita es demasiado antigua.

Descargar .deb
@DEB_SIZE@x86_64
Instalar
sudo apt install ./@DEB@

SHA-256 del .deb: @DEB_SHA256@

Fedora y openSUSE

.rpm

Fedora 43 o posterior y openSUSE Tumbleweed. En openSUSE, cambia dnf por zypper; allí las versiones nuevas se instalan a mano, descargando el paquete de nuevo.

Descargar .rpm
@RPM_SIZE@x86_64
Instalar
sudo dnf install ./@RPM@

SHA-256 del .rpm: @RPM_SHA256@

Qué hace

  • Todos tus proyectos

    Añade carpetas de Compose o crea otras nuevas. Cada proyecto muestra si está en marcha, parado o a medias.

  • Servicios y registros

    Arranca, para y reinicia cada servicio, ábrelo en el navegador y sigue sus registros en directo.

  • Plantillas

    Crea proyectos de PHP, WordPress, Drupal, Symfony, Node.js, Python o PostgreSQL, con contraseñas generadas en el .env.

  • Añade servicios

    Bases de datos, servidores web, Adminer o Mailpit, cada uno en su propio archivo de Compose. Si la comprobación falla, se deshace todo.

  • Editor de configuración

    Edita los archivos de Compose, el .env y los Dockerfile con resaltado de sintaxis, y valida la configuración con docker compose config.

  • Recursos de Docker

    Mira cuánto ocupan los contenedores, las imágenes y los volúmenes de cada proyecto, y libera espacio. Cada borrado pide confirmación.

  • Traefik

    Muestra la dirección de los servicios que enruta Traefik, como blog.localhost, y la abre en el navegador.

  • En segundo plano

    Al cerrar la ventana, sigue vigilando tus proyectos, con un icono en la bandeja en los escritorios que lo admiten.

  • Se actualiza con el sistema

    El paquete añade el repositorio de DockStation, así que las nuevas versiones llegan con apt o dnf, como el resto de tus programas. En openSUSE no: zypper no usa este repositorio.

Requisitos

Sistema
Linux de 64 bits (x86_64), con GTK 4.14 y libadwaita 1.6 o posteriores. El gestor de paquetes las instala solo.
Docker
Docker con el complemento de Compose v2 (2.20 o posterior para añadir servicios). El paquete lo recomienda, así que se instala con él salvo que lo desactives.
Permisos
Tu usuario debe poder usar Docker sin sudo: sudo usermod -aG docker $USER, y vuelve a iniciar sesión.

Primeros pasos

  1. Instala el paquete y comprueba que docker ps funciona sin sudo en una terminal.
  2. Abre DockStation desde el menú de aplicaciones.
  3. Pulsa Ctrl+O para añadir una carpeta que ya tenga un proyecto de Compose, o Ctrl+N para crear uno nuevo a partir de una plantilla.
  4. Pulsa Iniciar en el proyecto y sigue sus servicios y registros desde la misma ventana.
